## dma: Run one transfer and collect its completion

Stage a descriptor, submit it, wait for the completion record, check it and release it.

- write `dma.SRC` = `0x20000000`
- write `dma.DST` = `0x80000000`
- write `dma.LEN` = `0x1000`
- set `dma.TAG.TAG` = `0x7` (read-modify-write of rw bits only)
- write `dma.START` = `0x1`
- poll until `dma.CPL_STATUS.VALID` == `0x1` (at most 100000 reads)
- check `dma.CPL_STATUS.ERR` == `0x0`
- write `dma.CPL_POP` = `0x1`

    sf_dma_tag_set_tag(UINT32_C(0x7));
    sf_dma_start_write(UINT32_C(0x1));

        while (sf_dma_cpl_status_get_valid(sf_dma_cpl_status_read()) != UINT32_C(0x1)) {
