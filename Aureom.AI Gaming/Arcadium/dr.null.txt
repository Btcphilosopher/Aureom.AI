🌀🎮 GAME FRAME
VELOCITY BRITANNIA: DOCTOR NULL PURSUIT SYSTEM
🧠 CORE PREMISE

An Anglo-futuristic Britain has been warped by an AI-industrial geneticist known only as:

🧪 “Doctor Null”

He is transforming the island into a living acceleration experiment — turning infrastructure, wildlife, and cities into a controlled speed ecosystem.

You are not racing for sport.

You are:

escaping a continent-scale pursuit system that adapts to your movement.

🏃 CORE GAME LOOP
Spawn → Accelerate → Evade Doctor Null’s Systems → Chain Movement Routes → Rescue Allies → Break Pursuit Locks → Reach Safe Zone → Escalate World Difficulty
🧬 PLAYABLE CHARACTERS (8 BRITISH ANIMAL RUNNERS)

Each character is a bio-engineered “escape variant” with distinct movement physics and traversal advantages.

🦊 1. FOX — “ROOK”

Role: Balanced tactical runner

medium speed / high control
wall-slip traversal ability
can “thread” tight infrastructure gaps
bonus: reduces detection from Doctor Null tracking systems

👉 Best for: precise routing + survival stability

🐰 2. HARE — “FLUX”

Role: Pure acceleration specialist

highest top speed in game
extreme boost chaining
momentum multiplier scaling
weak turning control at high speed

👉 Best for: speed escapes + long straight industrial runs

🦌 3. STAG — “CROWNLINE”

Role: terrain breaker / momentum tank

can smash through weak barriers
stable high-speed handling
gains speed from downhill industrial slopes
resistant to collision slowdown

👉 Best for: destructive escape paths + heavy terrain zones

🦡 4. BADGER — “BURROW”

Role: underground escape specialist

tunnel traversal ability
can bypass surface pursuit systems
immune to most drone tracking above ground
slower surface speed but unmatched routing safety

👉 Best for: stealth escape routes + underground networks

🦅 5. FALCON — “AERO”

Role: aerial traversal / vertical escape

glide + dive mechanics
airborne speed bonuses
can cross broken infrastructure gaps
weak on ground friction zones

👉 Best for: vertical megastructure escapes

🐺 6. WOLF — “PACKRUNNER”

Role: adaptive pursuit counter-system

speed increases when chased
AI “echo decoy” trails confuse Doctor Null systems
can temporarily sync with other players for boosts
balanced all-rounder

👉 Best for: multiplayer synergy + reactive escapes

🦔 7. HEDGEHOG — “SPINCORE”

Role: defensive speed weapon

spin-state invulnerability bursts
can ricochet off obstacles for speed gain
destroys weak drones on contact
harder to control at low speed

👉 Best for: chaotic high-risk escape lanes

🦦 8. OTTER — “CURRENT”

Role: fluid movement specialist

water + industrial fluid system traversal
high control in slippery environments
can “ride” drainage and coastal flow systems
gains speed in liquid infrastructure zones

👉 Best for: coastal + canal + industrial fluid networks

🧠 DOCTOR NULL SYSTEM (PURSUIT AI)

The antagonist is not a character — it is a system.

It generates:

adaptive chase routes
infrastructure lockdowns
predictive interception zones
biomechanical traps
“speed correction fields” that counter player momentum

The faster you get, the smarter the world becomes.

🌍 WORLD REACTION SYSTEM

The world evolves based on player behavior:

too much fox usage → tighter corridors
too much hare speed → more interception zones
too much aerial movement → anti-air drones
underground dominance → tunnel collapse risks

So gameplay becomes:

an evolving counter-simulation of your own strategies

🤝 MULTIPLAYER (1–8 PLAYERS LOCAL)

Players are:

escaping together OR independently in same world
competing for survival efficiency
rescuing or abandoning teammates dynamically

Key mechanic:

if one player slows too much, Doctor Null focuses the entire system on them

So weak performance creates group pressure.

⚙️ CORE DESIGN IDEA (IMPORTANT)

This is not just a platformer.

It is:

a dynamic pursuit simulation system disguised as a speed platform game

🚀 ONE-LINE PITCH

A high-speed Anglo-futuristic escape platformer where genetically engineered British animal runners flee a continent-scale AI system that adapts in real time to how they move.
