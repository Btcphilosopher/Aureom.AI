# OpenROAD-flow-scripts integration

FloorplanLab is a thin layer over the **installed** ORFS revision `ab2aaf0f` (2024-02-23); nothing
of OpenROAD/ORFS is re-implemented. This page records what was inspected in that revision and how
each FloorplanLab feature maps onto it.

## Inspected Makefile structure (flow/Makefile @ ab2aaf0f)

| Item | Finding | Use in FloorplanLab |
|---|---|---|
| Stage targets | `synth`, `floorplan`, `place`, `cts`, `route`, `finish`; per-step rules generated by `do-step` / `do-copy` | `synth` (dependency-checked) |
| No-dependency steps | `do-2_1_floorplan`, `do-2_2_floorplan_io`, `do-2_3_floorplan_tdms`, `do-2_4_floorplan_macro`, `do-2_5_floorplan_tapcell`, `do-2_6_floorplan_pdn`, `do-2_floorplan`, `do-3_1_place_gp_skip_io`, `do-3_2_place_iop`, `do-3_3_place_gp`, `do-3_4_place_resized`, `do-3_5_place_dp`, `do-3_place`, `do-3_place.sdc` ("supported interface … without checking for dependencies") | `floorplan-run` = 2_1…2_5, `floorplan-pdn` = 2_6 + copy, `floorplan-place` = 3_1…3_5 |
| Directories | `WORK_HOME`, `RESULTS_DIR/LOG_DIR/REPORTS_DIR/OBJECTS_DIR = $(WORK_HOME)/<kind>/$(PLATFORM)/$(DESIGN_NICKNAME)/$(FLOW_VARIANT)`; the aggregate `do-floorplan` creates them, single `do-*` steps do not | one `WORK_HOME` per run (`results/<id>/orfs`); FloorplanLab creates the directories (first run failed without them) |
| Variable query | `print-%`, `vars` | analysis scripts get ORFS's resolved variables via `make print-VAR` and reuse ORFS `load.tcl` |
| GUI | `gui_floorplan`, `gui_place`, `open_*` | `make floorplan-gui` |
| Tools | `OPENROAD_EXE`, `YOSYS_CMD`, `KLAYOUT_CMD` overridable | passed on the make command line |

## Variables / hooks used

| ORFS variable | Set by FloorplanLab to | Notes |
|---|---|---|
| `VERILOG_FILES`, `VERILOG_INCLUDE_DIRS`, `VERILOG_TOP_PARAMS` | design.yaml (+ platform tech files) | ab2aaf0f has **no `VERILOG_DEFINES`**: a generated `flp_defines.svh` is read first (Yosys keeps defines across files — verified) |
| `SDC_FILE` | rendered `constraints/sfv_soc_df.sdc.tmpl` | contains `set clk_period`, which ORFS parses for ABC |
| `ADDITIONAL_LEFS/LIBS/GDS` | IHP SRAM collateral (ORFS d0e5b3c) | documented mechanism for design macros |
| `SYNTH_HIERARCHICAL=1`, `MAX_UNGROUP_SIZE=1000` | keep RTL blocks for grouping | ORFS `synth_hier_report.tcl` |
| `DIE_AREA`, `CORE_AREA` | FloorplanLab MODE A/B geometry | `CORE_UTILIZATION` (ORFS) is never set: it divides *total* (macro + logic) area by a utilisation, which the brief forbids |
| `MACRO_PLACE_HALO`, `MACRO_PLACE_CHANNEL` | run spec | used by `macro_placement` (TritonMP) and `block_channels` |
| `MACRO_PLACEMENT_TCL` | generated manual placement (OpenDB `setLocation`/`setOrient`, FIRM) | `2_3_floorplan_tdms` becomes a copy, as ORFS does for manual placement |
| `IO_CONSTRAINTS`, `PLACE_PINS_ARGS` | `set_io_pin_constraint` edge regions; `-min_distance N -min_distance_in_tracks -corner_avoidance D` | logical pins only |
| `PDN_TCL` | `platforms/<pdk>/pdn.tcl` (platform grid + SRAM macro grid) | ORFS `pdn.tcl` sources it, then runs `pdngen` |
| `POST_PDN_TCL` | `scripts/orfs_hooks/post_pdn.tcl` | ORFS has its `check_power_grid` loop commented out ("CI issues"); FloorplanLab runs it here |
| `PLACE_DENSITY_LB_ADDON` | 0.20 (default) | note: `global_place_skip_io.tcl` uses `lb + addon + 0.01`, `global_place.tcl` uses `lb + (1-lb)·addon + 0.01` |
| `GLOBAL_PLACEMENT_ARGS` | only on a recorded retry after `GPL-0307` (`-max_phi_coef 1.02`) | the tool's own instruction |
| `TNS_END_PERCENT` | 100 | repair all endpoints |

## Commands confirmed in the pinned OpenROAD (`help …`)

`initialize_floorplan` (die/core *or* utilisation), `make_tracks`, `place_pins` /
`set_io_pin_constraint`, `macro_placement` (TritonMP: halo, channel, fence, style),
`place_cell` and OpenDB `setLocation`, `cut_rows`, `tapcell`, `define_pdn_grid -macro
-grid_over_boundary`, `add_pdn_stripe/ring/connect`, `pdngen`, `check_power_grid -error_file`,
`analyze_power_grid`, `global_placement`, `detailed_placement`, `check_placement`,
`estimate_parasitics -placement|-global_routing`, `report_checks -path_group`, `global_route
-allow_congestion -congestion_report_file`, `report_wire_length -global_route`, `write_def`,
`save_image`.

**Not available in this build:** `rtl_macro_placer` (Hier-RTLMP; `RTLMP_FLOW` therefore
unsupported), `place_macro`, `report_congestion`. FloorplanLab rejects configurations that would
need them.

## Tool problems met and how they were handled (all recorded in run records)

| Problem | Evidence | Handling |
|---|---|---|
| `do-*` steps fail without LOG/REPORTS dirs | first A run: `couldn't open …/2_floorplan_final.rpt` | directories created before every make call |
| Core origin snapped by `initialize_floorplan` (`IFP-0028`) | first A run | x margin snapped to the site width, y margin to the row height |
| `GPL-0302` target density too low | A attempt 1 (0.60 fixed; tool suggested 0.66) | `PLACE_DENSITY_LB_ADDON` (density follows each floorplan) |
| `GPL-0307` RePlAce divergence | E, L_periphery_rows attempt 1 | one retry with `-max_phi_coef 1.02`, first log kept |
| SIGSEGV in OpenSTA multi-threaded delay calc during FastRoute | B attempt 1 (`sta::GraphDelayCalc::findMultiDrvrNet`, `DispatchQueue`) | global route left single-threaded, as in ORFS `global_route.tcl` |
| `PDN-0179 Unable to repair all channels` | C, D attempt 1 | side-by-side macro gap ≥ vertical strap pitch + width (PDN_CHANNEL rule) |
| `PSM-0069` VDD disconnected / `PDN-0110` no via M4→M5 | A attempt 1 | SRAM PG pins are vertical Metal4 → connect to horizontal TopMetal1 (ORFS reference) + coverage rule |
| Island via stacks (PSM-0069 on VDD+VSS, ~110 k nodes) | A attempt 2 (macro-only TopMetal1 straps) | macro grid without own straps; core TopMetal1 pitch 30.24 µm |
